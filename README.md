# Recondition House Nepal — Componentized React + Tailwind

This version is split into reusable React components instead of putting the whole UI in one JSX file.

## Structure

```text
src/
├── components/
│   ├── Header.jsx
│   ├── Logo.jsx
│   ├── Hero.jsx
│   ├── SearchBar.jsx
│   ├── CategorySection.jsx
│   ├── BikeCard.jsx
│   ├── FeaturedListings.jsx
│   ├── WhyChooseUs.jsx
│   ├── LatestListings.jsx
│   ├── Footer.jsx
│   ├── FooterColumn.jsx
│   ├── FeatureItem.jsx
│   └── Toast.jsx
├── data/
│   └── bikes.js
├── App.jsx
├── main.jsx
└── index.css
```

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The imagery uses remote Unsplash URLs as placeholders. Replace them with your own licensed production assets.
